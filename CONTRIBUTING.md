# Contributing to turboDNS

Thanks for your interest in contributing!

How we work
- Discuss significant changes in a GitHub Discussion first
- Small, focused pull requests are preferred
- Keep PRs readable and include rationale

Local checks
- Write shell scripts POSIX-compatible where feasible
- Run shellcheck and shfmt before submitting
- Lint Dockerfiles with hadolint

Commit style
- Conventional Commits are encouraged (e.g., "feat:", "fix:", "chore:")

PR checklist
- [ ] CI passes (lint/tests)
- [ ] Docs updated when behavior changes
- [ ] Clear description and motivation
